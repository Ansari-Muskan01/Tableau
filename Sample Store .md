## Data Description

The Superstore Sales dataset contains order-level information about products sold to customers across different cities, states, and regions of the United States. It includes customer details, product categories, order and shipping dates, sales amounts, quantities, discounts, and profits.

This dataset helps users practice data cleaning, calculated fields, data visualization, and business analysis using tools such as Tableau, Power BI, and Excel.

## Column Description

| Column Name | Description |
|---|---|
| Row ID | Unique row number for each record. |
| Order ID | Unique identifier for a customer order. Multiple products can belong to the same order. |
| Order Date | Date when the order was placed. |
| Ship Date | Date when the order was shipped. |
| Ship Mode | Shipping method selected for the order. |
| Customer ID | Unique identifier for each customer. |
| Customer Name | Name of the customer. |
| Segment | Customer segment, such as Consumer or Corporate. |
| Country/Region | Country or region where the customer order was placed. |
| City | City associated with the order. |
| State | State associated with the order. |
| Postal Code | Postal code of the location. |
| Region | Sales region associated with the order. |
| Product ID | Unique identifier for each product. |
| Category | Main category of the product. |
| Sub-Category | More specific classification of the product. |
| Product Name | Name of the product sold. |
| Sales | Total sales amount for the product line. |
| Quantity | Number of units ordered. |
| Discount | Discount applied to the product line. |
| Profit | Profit or loss generated by the product line. |
